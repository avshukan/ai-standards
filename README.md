# AI Standards

Переиспользуемые стандарты работы с ChatGPT и другими AI-инструментами.

## Standards

- [Session Coordination Protocol](SESSION_COORDINATION.md) — координация независимых рабочих сессий: роли, иерархия, планы, дистилляты, интеграция результатов и завершение.

Стандарты не заменяют инструкции конкретного проекта, его исходный код или источники истины.

## Adoption

1. Выбрать стандарт и проверить его совместимость с действующими правилами проекта.
2. Добавить копию документа в ChatGPT Project Sources или явно передать нужную версию в рабочую сессию.
3. Добавить короткую ссылку на документ в Project Instructions. Не копировать в них весь протокол.
4. Проверить поведение на небольшом пилоте перед регулярным использованием.

См. раздел «Adoption in another project» в [Session Coordination Protocol](SESSION_COORDINATION.md).

## Maintenance

- Эталонные документы хранятся здесь, а изменения отслеживаются через историю Git.
- Копии в других ChatGPT Projects не обновляются автоматически.
- Для применения новой редакции в другом проекте требуется отдельное явное действие.
- При переносе можно указывать конкретный commit SHA для однозначной фиксации редакции.
- Проектные дополнения и ограничения остаются локальными. Не переносите их в общий стандарт без отдельного решения.

Отдельный release-процесс, CI/CD и автоматическая синхронизация пока не вводятся.
